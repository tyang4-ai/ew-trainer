Egyptian War Trainer, offline version

Upload every file and folder in here to a static host (GitHub Pages works and is free).
Open the address in Safari on your iPhone, tap Share, then Add to Home Screen.
Open it once from the home screen while you're online. After that it works without internet.
To update later, push to main. GitHub Actions redeploys the site and bumps the cache version in sw.js automatically, so installed copies pick up the new version.
